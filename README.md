### 🚀 Featured Projects

#### **[dlpduck](https://github.com/c0dewhacker/dlpduck)**
A lightweight Data Loss Prevention (DLP) utility designed to inspect, sanitize, and detect sensitive data before it leaves local environments or pipelines.

<br />

#### **[Roomer](https://github.com/c0dewhacker/Roomer)**
A privacy-centric, self-hosted platform for managing desk and asset reservations across physical office spaces without relaying occupancy data to third-party SaaS services. Built with Node.js/Fastify, React/Vite, TypeScript, and PostgreSQL.

<br />

#### **[ScrubChef](https://github.com/c0dewhacker/ScrubChef)**
A privacy-focused data scrubbing and transformation tool powered by a high-performance WebAssembly (WASM) engine for client-side processing.
